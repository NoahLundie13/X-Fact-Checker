# X Fact Checker

This is a Chrome Extension that adds fact checking abilities to X. Using OpenAI's oss 120b model, we use internet search to fact check the tweet, and provide sources. The button is only applied to tweets that are pre-scanned to contain claims. 

This Fact-Checker is published on the chrome webstore [Here](https://chromewebstore.google.com/detail/tweet-fact-checker/oindinllpggjmeiofcchlpkjpjhhhgko)
